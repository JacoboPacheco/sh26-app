Make sure the script visibly hits all five judging criteria: Completion (show it working end to end, no "imagine this part"), Design (let the UI breathe for a beat), Technology (name the hard part in one sentence), Originality (the twist), Practicality (who uses it and how, in one line).
   - **Devpost writeup:** Inspiration, What it does, How we built it (stack + the interesting technical piece), Challenges, Accomplishments, What's next (the `LATER:` lines in CLAUDE.md → Current status plus anything demoted from Scope). Plain language, no hype words. Include the sponsor challenges it qualifies for and why, one line each, as the list to opt into on Devpost (plus Best First-Time Hacker if CLAUDE.md → Decisions → `Facts:` says first hackathon; no such line → ask), and a **Submission fields** line: GitHub repo URL, the user's Discord tag (ask), the video link placeholder.

Put a one-sentence spoken version of it in the demo script's "under the hood" step.
